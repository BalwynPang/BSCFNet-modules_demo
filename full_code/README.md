# Full Code Release

The complete BSCFNet source code, including the full network architecture, training pipeline, inference scripts, dataset preprocessing workflow, evaluation scripts, and repair-validation pipeline, is not publicly available at this stage.

This is because the complete implementation is associated with an ongoing funding project that has not yet been declassified or publicly released.

After the funding project is declassified and approved for public release, the related source code and additional implementation details will be updated in this directory.
